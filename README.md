This is a simple project I made based around a space defender in a different style. You revolve round the earth and shoot asteroids coming in. Try to avoid all asteroids from hitting the earth.
The controls are pretty simple: Left and Right arrows for rotating. And Space bar for shooting.

I used Plain HTML, CSS and JS for this project. with a simple gamloop system. Also added simpe animations and camera shake which REALLY makes the game feel better. Was a nice project i enjoyed making. Hope you enjoy!

to Run it, go to the [Live Page](https://the-earth-defender.netlify.app/). Or you can run it locally.
Download the project and run it throught cmd.
